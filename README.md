# Research Notes

연구 할일 · 분석 기록 관리 페이지. 데이터는 본인 Google 스프레드시트에 저장되고, 매일 퇴근 시간에 아이폰 메모(iCloud › RESEARCH NOTES)로 그날 기록이 넘어간다.

```
[앱: GitHub Pages (index.html)] ──POST──▶ [Apps Script 웹앱 (apps-script/Code.gs)] ──▶ [Google 스프레드시트]
                                                ▲
[아이폰 단축어, 평일 퇴근 시간] ──GET ?api=notes──┘ ──▶ 메모 앱 (날짜 제목)
```

| 파일 | 역할 | 어디에 |
|---|---|---|
| `index.html`, `manifest.webmanifest`, `sw.js`, `icons/` | 앱 화면 (Windows Edge 앱 · 아이폰 홈 화면) | GitHub Pages |
| `apps-script/Code.gs` | 데이터 저장 · API · 메모 텍스트 생성 | Apps Script 편집기 |
| `apps-script/Index.html` | (예비용) Apps Script 안에서 바로 열리는 예전 페이지 | Apps Script 편집기 |

이 저장소에는 URL·키·데이터가 들어 있지 않다. 연결 정보는 각 기기 브라우저에만 저장된다.

---

## A. Apps Script (데이터 · API)

최초 설치
1. Google 스프레드시트 새로 만들기 → **확장 프로그램 → Apps Script**
2. `Code.gs` ← `apps-script/Code.gs`, HTML 파일 `Index` ← `apps-script/Index.html` 붙여넣기 → 저장
3. 함수 `setup` 실행 → 권한 승인 → 실행 로그의 **KEY** 보관
4. **배포 → 새 배포 → 웹 앱** (실행: 나 / 액세스: **모든 사용자**) → `/exec` URL 보관

코드 수정 후: **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** (URL·KEY 유지)

## B. GitHub Pages (앱 화면)

1. 이 폴더 내용을 GitHub 저장소(공개)에 올린다
2. 저장소 **Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save**
3. 1~2분 뒤 `https://<GitHub아이디>.github.io/<저장소이름>/` 에서 열림
4. 첫 화면에 Apps Script `/exec` URL과 KEY 입력 → 연결

## C. 기기별 설치

**Windows (Edge)**
1. 위 주소 열기 → 연결 → **… → 앱 → 이 사이트를 앱으로 설치**
2. 작업표시줄 아이콘 우클릭 → **작업 표시줄에 고정**
3. `edge://apps` → 앱 **세부 정보 → 장치 로그인 시 자동 시작** 켜기 (알림을 받으려면 앱이 실행 중이어야 함)
4. 앱에서 **ETC 탭 → 이 기기 설정 → 알림 켜기** → 테스트
5. Windows **설정 → 시스템 → 알림**에서 이 앱 알림이 켜져 있는지, 방해 금지가 꺼져 있는지 확인

**아이폰**
1. PC 앱의 **ETC 탭 → 이 기기 설정 → 기기 연결 링크** 복사 → 아이폰으로 보내서 Safari로 열기 (자동 연결)
2. 공유 → **홈 화면에 추가**
3. 홈 화면 앱을 처음 열 때 연결 화면이 나오면 같은 링크를 URL 칸에 붙여넣기

## 기능 메모

- **할일 3단계**: ✅ 완료 / ▶️ 진행중 / 💤 미룸(마감 지남, 자동). 앱 목록 왼쪽 아이콘을 누르면 완료 ↔ 되돌리기. 단계도 같은 기호
- **이모지**: 앱의 이모지는 `icons/emoji/`의 Noto 이모지 그림(테두리 없음)으로 그려서 PC·아이폰 동일. 아이폰 메모 앱 안의 이모지는 iOS가 그림
- **마감**: 오늘 / 내일 / 이번주 안(다가오는 금요일) / 직접 선택. 지나면 💤
- **단계(딸림 할일)**: 할일 편집 창에서 추가·수정·삭제 (저장 버튼으로 반영). 목록에서는 할일 아래에 단계가 항상 보이고 바로 체크 가능 (즉시 저장). 모든 단계를 체크하면 할일 자동 완료. 반복 할일의 다음 회차에는 체크 해제 상태로 복사. 메모에는 할일 아래 `   ✓ 내용` / `   · 내용`으로 넘어가고, 가져오기에서도 인식
- **단계 마감일**: 편집 창에서 단계마다 📅로 날짜 지정. 할일 마감을 비워 두면 단계 마감 중 가장 늦은 날로 자동 설정되고 단계 날짜가 바뀌면 따라감 (직접 입력한 마감이 우선). 메모에는 `   · 내용 (~11/12)`
- **반복**: 매일 / 평일 / 매주(요일 선택) / 매월(마감일의 날짜). 종료일을 비우면 계속 반복. 완료하면 다음 회차가 자동 생성되고, 완료를 취소하면 그 회차는 다시 지워짐. 아직 차례가 안 된 회차는 메모에 넘어가지 않음
- **알림**: 1시간 후 / 오늘 17시 / 내일 9시 / 직접 선택. 소리 없는 배너. 앱이 실행 중일 때(최소화 포함) 표시, 꺼져 있다 켜면 12시간 이내 놓친 알림은 바로 표시
- **아이콘 숫자**: 오늘 마감 + 마감 지난 할일 개수 (Edge 앱 작업표시줄)
- **동기화**: 5분마다, 그리고 창으로 돌아올 때 자동 새로고침
- **분석 기록**: 🔶 기록 + 🔸 추가 정보 여러 개
- **Backlog**: 별도 탭. 태그를 새로 붙이거나 바꾸면 Research To-do로 자동 이동, 편집 창 [To-do로 보내기 / Backlog로 보내기], PC는 할일을 위쪽 탭에 끌어다 놓기. 메모·알림·아이콘 숫자에서 제외
- **할일 메모**: 편집 창의 메모 칸. 목록에 첫 줄 표시, 검색 대상. 아이폰 메모에는 할일 바로 아래 들여쓴 `🔸` 줄로 넘어감 (가져오기에서도 인식)
- **탭 구성**: Research To-do · Backlog · Analysis Records · ETC(검색, 메모 가져오기, 아이폰 메모 내보내기·백업, 이 기기 설정)
- **검색**: 할일·분석 기록·프로젝트 검색 (여러 단어 AND, 결과를 누르면 편집), 기존 메모 가져오기

## 아이폰 단축어 (메모 자동 생성)

URL: `<Apps Script /exec>?api=notes&key=<KEY>&header=1` (앱의 ETC 탭 → 아이폰 메모 내보내기에서 복사)

자동화 → 특정 시간(평일 퇴근 시간, 즉시 실행) →
`URL` → `URL의 콘텐츠 가져오기` → `텍스트`(URL의 콘텐츠) → `만약 텍스트 값이 있음` → `메모 생성`(본문: 텍스트, 폴더: iCloud › RESEARCH NOTES)

메모 형식
```
2026. 11. 09. 月曜日
𝑹𝒆𝒔𝒆𝒂𝒓𝒄𝒉 𝑻𝒐-𝒅𝒐
✅ 그날 완료 / ▶️ 진행중 / 💤 미룸(마감 지남)
   ▶️ 단계 (~11/12) / ✅ 완료한 단계 / 💤 마감 지난 단계

𝑨𝒏𝒂𝒍𝒚𝒔𝒊𝒔 𝑹𝒆𝒄𝒐𝒓𝒅𝒔
🔶 [프로젝트] 기록
   🔸 추가 정보 (들여쓰기)
```
놓친 날: URL 끝에 `&date=2026-11-06`

## 백업 / 안전장치

- 스프레드시트 **파일 → 버전 기록**으로 복원 가능
- 삭제는 `status=deleted` 표시만 함 (시트에서 `open`으로 바꾸면 복구)
- ETC 탭 **전체 데이터 백업(JSON)**
- 키 유출 시 Apps Script에서 `resetKey` 실행 → 각 기기 재연결, 단축어 URL 교체
- 환자 식별정보 등 민감정보는 적지 않기
